// turbo-all

1. Kiểm tra git status xem có file nào chưa commit không
```bash
git status
```

2. Stash các thay đổi local (nếu có)
```bash
git stash
```

3. Pull code mới nhất
```bash
git pull origin master
```

4. Pop stash lại (nếu có)
```bash
git stash pop
```
